Rally Note スマホ版

このフォルダはスマホ向けのWebアプリです。

入力できる内容
- シングルス / ダブルスの選択
- 自分・対戦相手の名前
- 自分の所属チーム、相手の所属チーム
- ダブルス時だけ表示される2人目の名前入力
- 対戦日、試合会場、試合メモ
- 15点制・最大21点、2ゲーム先取のラリー分析

公開方法
1. このフォルダ内のファイルをHTTPS対応の静的ホスティングへアップロードします。
2. スマホで公開URLを開きます。
3. Android Chromeでは「アプリを追加」、iPhone Safariでは共有メニューの「ホーム画面に追加」を選びます。

必要なファイル
index.html / style.css / mobile.css / app.js / manifest.webmanifest / service-worker.js / icon.svg

GitHub Pagesを使う場合
GitHubの公開リポジトリのルートへ上記ファイルをアップロードし、Settings > PagesでDeploy from a branchを選択します。
HTTPSの公開URLが発行されると、スマホから利用できます。

データについて
試合記録は利用端末のブラウザ内に保存されます。端末間での同期は行いません。
